# eSystor redesign (sample pages)

Demo redesign for Systor Systems (esystor.com). Static HTML, no build step needed to view.

- `index.html` home page
- `collection.html` Tower SATA HDD/SSD duplicator collection (all 33 models, price grid and filters)
- `product.html` SYS103HS-DP product page
- `page.html` About us, government orders and contact

Header menus, footer links, product data, prices and photos come from the live esystor.com store, and links point to the real store pages. The language picker uses Google Translate like the live site.
